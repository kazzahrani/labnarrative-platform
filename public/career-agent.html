Your workflow

Review-first by design
1
Build the Master Profile

Your verified CV facts, research background, teaching, publications, credentials, and optional AI-building experience become the evidence base.

2
Choose Career Tracks

Enable the job families worth searching. The agent uses them as career hypotheses, not rigid keyword buckets.

3
Search official sources

Hourly automation keeps the radar current. Run search now performs a fresh scan and immediately rebuilds newly qualified application packages.

4
Review the application

Inspect the tailored CV PDF, cover-letter PDF, email draft, destination, and source posting before you take action.

5
Apply deliberately

Email-based roles will use a reviewed send flow once OAuth is connected. Portal-only roles stay portal-only; the agent never invents recipients.
